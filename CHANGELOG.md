# Changelog

## 0.1.0

- `<livewire:hibira.usage />` Pulse card: connections now and peak against the
  plan limit, messages today against the daily limit, data sent, a
  connections and messages chart for Pulse's period picker, and the busiest
  channels by subscriber count.
- Reads Hibira's account API (personal API token, read scope) and the
  Channels HTTP API; readings cached for 60 seconds.
- Texts in en, ja, ko, zh_TW, zh_CN, th, vi.
